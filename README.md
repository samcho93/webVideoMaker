# WebVideoMaker

Electron 기반 종합 비디오 편집기입니다. FFmpeg 이 앱에 포함되어 있어 별도 설치가 필요 없습니다.

## 주요 기능

| 영역 | 기능 |
| --- | --- |
| 불러오기 | MP4, MOV, AVI, MKV, WEBM, WMV 등 비디오, JPG·PNG 등 사진, MP3·WAV·M4A 등 음악, 폴더째 가져오기. 먼저 실제로 재생해 보고 그대로 재생되면 변환하지 않으며, 안 되면 다시 압축 없이 옮겨 담거나 미리보기용 파일을 생성. 결과물에는 항상 원본을 사용 |
| 컷 편집 | 타임라인 어디든 끌어다 놓기(맞지 않는 줄에 놓으면 가까운 트랙으로, 탐색기 파일도 가능), 이어 붙이기, 자르기, 트림, 구간 잘라내기(모든 트랙), 당겨서 삭제, 멀티 트랙, 자석 맞춤, 복사·붙여넣기, 실행 취소 |
| 해상도·방향 | 클립별 전체 맞춤/꽉 채우기/늘리기/블러 배경, 회전, 반전, 크롭, 크기, 위치. 세로 촬영 영상의 회전 정보와 사진의 EXIF 방향 자동 인식 |
| 전환 | 페이드 인/아웃, 크로스페이드 |
| 속도 | 지정 구간 빨리 감기·느리게(0.1~16배). 소리는 음높이 유지 |
| 모자이크·블러 | 사각/타원 영역, 강도, 시간 구간, 움직이는 대상을 따라가는 이동 경로 |
| 꾸미기 | 텍스트(글꼴·외곽선·그림자·배경), 아이콘, 이모지, 도형, 색 보정, 불투명도 |
| 음악 | 오디오 트랙, 볼륨, 페이드, 파형 표시 |
| 자막 | 직접 입력, SRT 가져오기/내보내기, 트랙별 스타일 |
| 나레이션 | 시:분:초 타임스탬프 파일 불러오기/출력, Windows 음성으로 합성해 삽입, 음성 파일 지정 |
| 저장 | 프로젝트 저장/열기(`.wvm`), 30초 자동 저장과 복구, 옮겨진 파일 다시 연결 |
| 내보내기 | MP4(H.264/H.265), WebM, MOV, MKV, GIF. 해상도·화질 선택, 진행률, 중단 |

## 나레이션 파일 형식

UTF-8 또는 메모장 ANSI(EUC-KR) 텍스트 파일입니다. 타임스탬프는 `시:분:초` 입니다.

```text
# 샵으로 시작하는 줄은 주석입니다
00:00:05 끝 시각을 생략하면 글자 수로 표시 길이를 정합니다.
00:00:12 - 00:00:18 끝 시각을 지정한 항목입니다.
타임스탬프가 없는 줄은 앞 항목의 다음 줄이 됩니다.
00:00:20 <audio:voice01.mp3> 음성 파일을 직접 지정합니다. (나레이션 파일 기준 상대 경로)
```

`자막·나레이션` 탭에서 불러온 뒤 `음성 생성하여 넣기`를 누르면 각 문장이 음성으로 합성되어 `나레이션 음성` 트랙에 들어갑니다. 글자를 숨기려면 `나레이션` 트랙의 🚫 를 누르세요.

## 개발

```bash
npm install
npm start
npm test
npm run test:render
npm run test:e2e
npm run dist
```

- `npm test`: 타임코드, 나레이션 파서, 배치 계산, 필터 그래프 단위 테스트
- `npm run test:render`: 실제 FFmpeg 렌더링 결과의 길이·픽셀·소리 검증
- `npm run test:e2e`: 실제 Electron 앱을 조작해 편집부터 내보내기까지 검증. 패키징본은 환경 변수 `WVM_EXE` 로 지정

## 구조

```text
main/       메인 프로세스 (창, media:// 프로토콜, FFmpeg 실행, 내보내기, 음성 합성)
renderer/   편집기 UI (미리보기 합성, 타임라인, 패널)
shared/     양쪽이 함께 쓰는 순수 모듈 (데이터 모델, 배치 계산, FFmpeg 그래프, 나레이션 파서)
tests/      단위·렌더링·E2E 테스트
```

미리보기와 결과물을 일치시키기 위해 배치 계산은 `shared/layout.mjs` 하나를 함께 쓰고, 텍스트·아이콘·자막은 렌더러가 PNG 로 그려 FFmpeg 에 넘깁니다.

## 알려진 제약

- 클립마다 FFmpeg 입력을 하나씩 열기 때문에 클립이 수백 개인 프로젝트는 메모리 사용량이 크게 늘고, Windows 명령줄 길이 제한에 걸릴 수 있습니다.
- 밝기 보정은 미리보기(곱셈)와 FFmpeg(덧셈)의 방식이 달라 약간 다르게 보일 수 있습니다.
- 4배속을 넘는 구간은 미리보기에서 소리가 나지 않을 수 있습니다. 결과물에는 정상 반영됩니다.
- HEIC 처럼 포함된 FFmpeg 이 읽지 못하는 형식은 가져올 수 없습니다.
- 타임라인 위쪽 경계를 끌어 높이를 바꿀 수 있습니다. 작은 창에서는 트랙이 가려질 수 있으며, 끄는 동안 가장자리에 머물면 자동으로 스크롤됩니다.
- 코드 서명을 하지 않아 설치 시 Windows SmartScreen 경고가 표시될 수 있습니다.
